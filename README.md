## Goal

- SQLite 데이터베이스를 대상으로 EF Core 리버스 엔지니어링을 반복 실습한다.
- 스캐폴딩 옵션별 결과 차이를 직접 비교한다.
- 학습 중 생성한 코드, 명령어, 의사결정 기록을 문서로 남긴다.
- 이후 작업도 AI가 문서를 읽고 바로 이어서 진행할 수 있게 만든다.
